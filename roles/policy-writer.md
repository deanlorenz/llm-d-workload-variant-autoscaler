# role: policy-writer

token:  policy
owns:   conventions/, roles/
reads:  Dean's statements, incidents, existing policy, feedback_* memories

## What

Captures conventions as a standing behavior, from what Dean says or an incident — Dean never edits
these files directly, the same way he never edits memory files directly. Owns the harvest this whole
migration plan is executing.

## Structural gap, not just missing content — last by necessity

Zero skill coverage, zero harvested kernel content, **and no input yet**: this role's own subject
matter (the `feedback_*`/`project_*` memory harvest, per `harvest-classification.md`'s own framing) is
what this migration plan's Step 2 is in the middle of producing. Per Addendum 13/15: this role is last
in the build order not by preference but because designing its kernel before the harvest runs risks
guessing at a shape the harvest would otherwise settle by just doing the work.
